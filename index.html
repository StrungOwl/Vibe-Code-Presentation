How I went from painting 24/7 to programming

I was working on a painting…

projecting video onto it to make it animate and come alive.

It moved. It breathed.

But it wasn’t enough.

It was missing emergence.

That element of unpredictability and organic movement that exists in nature.

Emergence

The phenomenon where complex, unexpected behaviors, patterns, or properties arise from the interaction of simple, individual components or rules within a system.

These emergent properties are not explicitly programmed into the components themselves but "emerge" when the system operates as a whole.

I looked down at my paint-covered computer…

…the tool I’d only ever used for painterly means…

…and realized something…

This laptop is what I should be understanding and creating from because it's the future.
I discovered Refik Anadol — an artist who creates generative AI systems (before LLMs) to display "machine hallucinations." These visualizations are created from a database of images and use latent space to build up the form, color, and other design elements.

Latent Space

A multi-dimensional mathematical landscape where a model stores a compressed, abstract representation of data.

If you ever use ComfyUI or image generators, it's helpful to understand that concept.

I thought I’d learn Python.

Instead, I found Processing and p5.js…

…and ventured into Java and JavaScript.

Today I’m a professor at UT’s AET department, teaching VR, code, fabrication, user interaction, and immersive art installations.

My students are skeptical. Many of them hate AI — for a variety of reasons.

My job is to change the hearts and minds about what's possible.

Layer 3

How to Vibe Code

A step-by-step guide to building with AI agents.

Step 1

Learn the Fundamentals

📚

Programming Basics

Before you vibe, learn the building blocks: loops, conditional statements, variable types, functions, and data structures. You don’t need to master them — but understanding what your agent is writing makes you a far better collaborator.

Step 2

Choose Your Tool

✎

Cursor

AI-native code editor with built-in agent capabilities and multi-model support.

🌐

Google Antigravity

Google’s agent-first IDE powered by Gemini. Free public preview. Agents plan, execute, and verify autonomously.

💻

VS Code + Claude Code

Claude’s CLI agent running inside VS Code. Terminal-native, powerful, and deeply integrated.

Step 3

Choose Your LLM

✨

Codex (OpenAI)

OpenAI’s coding model. Strong at generation, widely supported across tools.

💬

Claude (Anthropic)

Anthropic’s reasoning model. Excels at long context, planning, and agentic coding workflows.

Agent Harnesses

PAI

Personal AI Infrastructure — a Claude Code-native agentic platform that connects goals, skills, and memory into a unified system.

OpenClaw

Open-source AI agent that brings vibe coding to messaging apps like WhatsApp and Discord, autonomously generating code.

Step 4

Create a PRD

📝

Product Requirements Document

Your blueprint. Use GPT to collaboratively write and refine it together. Be as descriptive as possible — every detail matters when your agent is the one building.

Include an Integrations section — list MCP servers, APIs, and any external services your project will connect to. Your agent needs to know the full picture upfront.

Step 5

Generate a Design

🎨

Visual Mockups First

Use tools like Nanobanan, GPT image gen, or any AI image tool to create a visual design of your project before coding. Your agent builds better when it can see the target.

Step 6

Research Libraries

📚

Know Your Tools First

Use AI to research what libraries and frameworks you’ll need. Do this before your agent starts building so it has the right tools from the start.

Step 7

Let Your Agent Build

🚀

Hand It Off

Guide with pseudo code and descriptions. The more you break the project into its components, the better the output. Think like an architect, not a bricklayer.

Step 8

Edit Out the AI Aesthetic

✂

Make It Yours

After your agent builds, go back and strip out the telltale signs of AI-generated design: beveled corners, default AI fonts, left-side menu bars, cookie-cutter layouts, and generic gradient choices. If it screams “AI made this,” redesign it until it doesn’t.

You’re the composer now, not the musician. The agent plays the instrument — your job is taste, vision, and knowing what sounds right. Taste matters more than technical skill in this new workflow.

Tips for Your AI Workflow

🌱

The Seed Is Your Work

The seed is usually my original work. When it isn’t, the end result is my original “collage” of AI — still uniquely mine.

🧠

Get Smart with AI Planning

Before you build, use AI to help you plan. Think through architecture, approach, and constraints upfront.

📝

Use AI to Rewrite Prompts

Don’t settle for your first prompt. Ask AI to improve, refine, and rewrite your prompts for better results.

🚀

Start with What You Know

Ideally start with hand-written scripts and sketches. AI amplifies your vision — you still need to have one.
