Palettable Programming

A Painter's Journey into Code and AI

Sydney Parks

I was working on a painting…

projecting video onto it to make it animate and come alive.

It moved. It breathed.

But it wasn’t enough.

It was missing emergence.

Emergence

The phenomenon where complex, unexpected behaviors, patterns, or properties arise from the interaction of simple, individual components or rules within a system.

I looked down at my paint-covered computer…

…the tool I’d only ever used for painterly means…

…and realized something…

Latent Space

A multi-dimensional mathematical landscape where a model stores a compressed, abstract representation of data.

I thought I’d learn Python.

Instead, I found Processing and p5.js…

…and ventured into Java and JavaScript.

Today I’m a professor at UT’s AET department.

VS Code Using Claude Code extension
Playwright comes in two flavors worth knowing: the CLI (command-line runner) and the MCP server. Both use the same underlying engine, but they interact with the browser differently. The CLI drives the browser through the DevTools Protocol — raw pixel/DOM access. The MCP version exposes the accessibility tree instead: the same semantic tree that screen readers use to help blind users navigate interfaces. That tree describes buttons, headings, and landmarks by role and label, not by pixel position. This makes Claude's test interactions much more robust — it finds elements the way a human would describe them, not by brittle CSS selectors.

Choose Your Agentic Platform

Claude Code

Anthropic’s agentic coding CLI.

Claude Code

Anthropic’s agentic coding tool that lives in your terminal, understands your entire codebase, and helps you code faster through natural language. It can read issues, write code, run tests, and submit PRs autonomously — with extensions for VS Code, Cursor, and JetBrains.

Codex

OpenAI’s agentic coding platform.

Codex (OpenAI)

OpenAI’s cloud-based agentic coding platform that works on many tasks in parallel using isolated cloud environments. It includes a CLI, an app, and IDE extensions — supporting autonomous workflows like issue triage, CI/CD monitoring, and code review.

Agent Harnesses

PAI

Personal AI Infrastructure

PAI — Personal AI Infrastructure

A Claude Code-native agentic platform that connects goals, skills, and memory into a unified system. PAI studies and formulates best practices for responsible AI development, spanning media integrity, workforce impact, justice, transparency, and AI security.

OpenClaw

Open-source AI agent framework

OpenClaw

An open-source, self-hosted AI agent daemon that connects 12+ messaging platforms (WhatsApp, Telegram, Discord, iMessage, etc.) to AI coding agents. It ships with 100+ preconfigured skills for shell commands, file management, and web automation — all running on your own infrastructure with no telemetry.

Step 7

Let Your Agent Build

Best practices for prompting your agent. Hover each card for details.

Pseudo Code

Remember this concept and use it when you describe what you want.

A simplified, human-readable description of what your program should do — written in plain language, not actual code. It lets you think through logic without worrying about syntax.

“When the user clicks the canvas, generate a new shape at that position. Each shape should inherit the color of the previous one but rotate 15 degrees.”

Be Descriptive

The more detail you give, the better the output.

Instead of “make it look nice,” say: “Use a dark background (#0a0a0a), thin white lines, and animate them with a sine wave that oscillates every 3 seconds.”

Break the project into components: layout, interaction, animation, color, typography. Describe each one separately.

Think Like a Composer

Each chat is a different musician in your orchestra.

Every musician in an orchestra has a strength. Treat each chat the same way — one for planning, one for building, one for troubleshooting, one for editing, one for critique. Don’t cross-pollinate.

UI Testing with Playwright CLI

Let your agent do the testing for you.

Playwright CLI lets your agent open a real browser, interact with your UI, and verify it works — all without you lifting a finger. Describe what to test and let Claude run it.

Step 7 — Continued

Let Your Agent Build

Useful /commands to know about

/model

Switch models mid-session. Use Opus for hard problems, Haiku for fast simple tasks.

Not every task needs the most powerful model. Match the model to the job:

Opus — complex reasoning, architecture decisions, hard bugs

Sonnet — everyday building, writing, iteration

Haiku — fast, lightweight tasks: quick edits, simple lookups, high-volume automation where speed and cost matter

/clear

Wipe the conversation and start fresh. Use between features to keep context clean.

/compact

Manually summarize the session to free up context space before hitting the limit.

When you hit the context limit, the agent auto-compacts: it summarizes earlier work to free up space but loses detail. Use /compact manually before that happens, or start a new chat when finishing a feature.

/mcp

Manage your MCP servers (plugins) — connect Figma, GitHub, browser control, and more.

/plugin

Install and manage Claude Code plugins — extend your agent with custom tools and integrations.

/context

Shows a snapshot of what’s currently loaded into your conversation’s context window — everything consuming tokens right now.

Bonus Tip

Stop Clicking “Accept”

Open Explorer, navigate to the .claude folder, open settings.local.json, and paste in the following permissions.

{
  "permissions": {
    "allow": [
      "Bash",
      "Read",
      "Edit",
      "Write",
      "MultiEdit",
      "Grep", "Glob", "LS",
      "WebFetch",
      "WebSearch",
      "NotebookRead",
      "NotebookEdit",
      "TodoRead", "TodoWrite"
    ]
  }
}

Highlighted = common requests from Claude.

Bash — run shell commands (npm, git, scripts) Edit — modify files with diffs Write — create or overwrite files MultiEdit — batch edits in one shot WebFetch — pull content from a URL WebSearch — search the web
Step 8

Edit Out the AI Aesthetic

Make It Yours

After your agent builds, go back and strip out the signs of AI-generated design.

Copy and paste the list to the right — or create your own updated version based on what you learned in the AI landscape phase — into the chat and double check that it avoided these designs.

Also put the list in your PRD so it knows not to use it from the beginning.

Things That Look Like AI

  • Beveled corners on everything
  • Default AI fonts (Inter, system defaults)
  • Left-side menu bars
  • Cookie-cutter layouts
  • Generic gradient choices
  • Affordance design that glows
  • Overly polished glass/blur effects
  • Centered hero sections with stock phrases
  • Floating cards with drop shadows
  • Icon-heavy minimal dashboards

Example: openclaw.ai
